# EMF Books accounting app prototype

This is a responsive, single-file front-end prototype. It has no external libraries or build step. Open `index.html` in a modern browser to explore the interface.

## Included

- Overview dashboard with demo income, expenses, estimated cash position, and six-month chart.
- Add and search income or expense transactions.
- Create customer invoices and mark them paid. Marking an invoice paid creates an income transaction.
- Basic transaction summaries and monthly performance reports.
- Download transaction records as CSV.
- Browser-local demo storage and a reset option in Settings.

## Prototype limitations

The sample workspace is fictional. Records are saved only in the current browser; there is no sign-in, shared database, server backup, or multi-user access. The summaries are based on transaction entries and do not constitute a double-entry general ledger, tax calculation, bank reconciliation, or statutory financial statements. Connect a secure backend and have the accounting rules reviewed before using real client records or publishing this as a production accounting service.
